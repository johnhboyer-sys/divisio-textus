# Codex review, 2026-10-30

Whole-app adversarial review (GPT-6.1-Sol, medium) of commit 80f5493. Nothing here
is fixed yet. Line numbers are from that commit.

"Ran" means reproduced with a scratch test on drawn pages. "Read" means confirmed
by reading the code only.

## Fix first

1. **Grayscale export turns off the OCR corrections. Ran.**
   `OCRService.scaled` (OCRService.swift:342) pairs a gray image's color space with
   `.noneSkipLast`. The context is created, but what it draws is solid black, so the
   half-size and 0.75-size readings find no lines. Color mode, the default, is fine.
   Codex said the context fails and the image stays full size; that part is wrong.
2. **A plate near the page edge gets cut. Ran.**
   `bandEnd` (PageAnalyzer.swift:611) takes a dark plate for a scanner band when it
   starts within 3% of the edge and fills over 85% of the height. Both crop modes.
   On a 1700×2200 page: a plate at x=34, 1630 wide and 90% tall, gave a crop of
   x 0.979–1.0; a 620-wide plate beside text gave x 0.385–1.0 in Whole page mode.
3. **Saved edits can be wiped. Read.**
   `ProjectStore.load` (ProjectStore.swift:57) returns nil for a decode error or
   another version, the same as no save. `AppModel.load` then starts fresh and
   autosave writes over the record.
4. **A failed save can lose edits. Read.**
   `saveEdits` (AppModel.swift:1690) catches the error, so `load` (AppModel.swift:233)
   and quitting carry on and drop the edits. The message runs but stops nothing.
5. **Export can report success on a bad file. Read; the failure itself is plausible.**
   Nothing checks the temporary PDF before it replaces the destination
   (PDFExporter.swift:175). A full disk could leave a truncated file.

## OCR text

6. **A centered page number is lost on two-column pages. Ran.**
   `LayoutAnalyzer.columnBlocks` (LayoutAnalyzer.swift:155) returns full-height columns
   that stop above it. A real "127" below two columns of text got no text layer.
7. **A row can be doubled. Ran.**
   In `merge` (OCRService.swift:449), pass 1 "left part" + "right part" and pass 2
   "left part right part" give all three lines: the whole line's centre falls in the
   gap, so no pass 1 box holds it.
8. **Right foreign words can be replaced. Read.**
   `spelledRight` (OCRService.swift:195) checks only the first language, `en-US`. A
   correct "nicht" would become "night" if the half-size reading saw that.

## Smaller or rare

- Export reopens the source path without checking its hash, so a file swapped after
  opening gets the old edits (AppModel.swift:1635). Read.
- Thin page numbers fall outside Crop to Text (PageAnalyzer.swift:794): rows need
  over 1% dark pixels. A number 14 px wide on a 1700 px page was left out. Ran.
- An old-format save can attach to a different PDF with the same size, page count
  and first 4 MB, and the migration then deletes the old record (AppModel.swift:253). Read.
- Very tiny crops come out bigger than shown or spill past the trim: `normalize`
  forces 2% of the scan, while the box's limit is 2% of the trim
  (PDFRenderer.swift:259, BookPage.swift:113, PageEditorView.swift:167, :193, :216). Read.
- Inverted pages lose a 2% edge strip through `fullSubRange` (PageAnalyzer.swift:713). Ran.
- A drag cut off by switching views may leave `editSnapshot` set, so the next page's
  edit gets no undo (CropBoxView.swift:89, AppModel.swift:1532). Needs checking in the app.
- A block that can't be cropped or padded isn't counted in `failedBlocks`
  (OCRService.swift:63). Read.
- Words only the half-size reading found are dropped ("alpha beta" against "alpha beta
  gamma", OCRService.swift:459). Adding them could bring in made-up words: test on real
  books first. Read.
- "6,5" isn't accepted as a page size (BookPage.swift:172). Read.

## Left alone

- Landscape single pages are guessed as spreads (PageAnalyzer.swift:68): a starting
  guess the user can change.
- Color marks under 0.005% of the page count as gray (ImageEnhancer.swift:30): the
  intended limit.
